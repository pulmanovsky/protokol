# Install

1. Download the `.dmg` from [Releases](https://github.com/pulmanovsky/protokol/releases/latest).
2. Drag **Протокол** to Applications.
3. macOS may block the first launch: System Settings → Privacy & Security → **Open Anyway**.
4. Allow the microphone and screen recording. Screen recording is used only for call audio.
5. Download the models (about 10 GB) or install them from a folder when offline.
