# Settings

Microphone and call audio, recognition model, dictionary, document templates and updates. An organisation's template or set of templates (a .json file) is added with **Імпорт із файлу** (Import from file) under «Шаблони документа» (Document templates): it brings the templates, and dictionary terms and document wording when the file has them. Your own template is saved to a file with **Зберегти у файл** (Save to file) in its editor.
