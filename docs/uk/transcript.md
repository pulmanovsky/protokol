# Стенограма

Натисніть слово, щоб прослухати його. Непевні слова підкреслені, кнопка «Перевірте» проводить по них. Виправте слово прямо в тексті: програма запам'ятає правило. ⌘Z скасовує зміну.

Копіювання: кнопка на панелі копіює всю стенограму зі спікерами та часом, значок біля імені копіює текст одного спікера.
