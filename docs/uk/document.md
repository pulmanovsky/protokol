# Документ

Документ складається з виправленої стенограми за шаблоном, який вибирається у вкладці «Документ»: «Підсумки доповідачів» (вижимка кожного спікера та загальний підсумок), «Рішення та завдання», «Доповіді за полями», «Стенограма» або власний шаблон. Кожен створений документ зберігається під своїм шаблоном: кнопка шаблону над документом показує вже створені та створює новий за іншим шаблоном. Якщо стенограму виправили після створення документа, над ним з'являється «Оновити документ».

Значок праворуч від імені копіює блок одного спікера. Документ можна зберегти у DOCX чи PDF. Шаблони налаштовуються в «Налаштування → Шаблони документа».
