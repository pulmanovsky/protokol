# Налаштування

Мікрофон і звук дзвінка, модель розпізнавання, словник, шаблони документа та оновлення. Шаблон чи набір шаблонів організації (файл .json) додається кнопкою **Імпорт із файлу** у розділі «Шаблони документа»: з нього приходять шаблони, а також терміни для словника та формулювання документа, якщо вони є у файлі. Власний шаблон можна зберегти у файл кнопкою **Зберегти у файл** у його редакторі.
