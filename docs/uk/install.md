# Встановлення

1. Завантажте `.dmg` зі сторінки [Releases](https://github.com/pulmanovsky/protokol/releases/latest).
2. Перетягніть **Протокол** у «Програми».
3. Під час першого запуску macOS може заблокувати програму: Системні параметри → Приватність і безпека → **Усе одно відкрити**.
4. Дозвольте мікрофон і запис екрана. Запис екрана потрібен лише для звуку дзвінка.
5. Завантажте моделі (приблизно 10 ГБ) або встановіть їх із папки, якщо мережі немає.
