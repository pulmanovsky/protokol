# Протокол 0.4.6

## latest.json (вікно оновлення)

Точніший поділ стенограми за мовцями: рядок більше не захоплює слова іншого учасника, а мовлення, яке раніше пропускалося, розпізнається окремо. У розділі якості видно, що саме виправляється в стенограмах. Програма стала меншою, а модель розпізнавання перевіряється за контрольною сумою.

## GitHub release v0.4.6

- Рядок стенограми закінчується там, де починає говорити інший учасник, навіть якщо його слова не було розпізнано. Час рядка більше не розтягується на чужі репліки чи довгу паузу.
- Відрізки, де учасник говорив 2 с і більше, а тексту немає, розпізнаються ще раз окремо. Явно вигадані фрази та повтори сусіднього тексту відкидаються.
- У розділі якості розпізнавання з'явився блок «Що виправляли»: частка виправлених слів за видами (назви, числа, закінчення, заміни, додані та прибрані слова) та кількість рядків, переданих іншому мовцю, за останні наради.
- Цифри про види виправлень додано до звіту про якість, який надсилається лише за згодою.
- Містить усі зміни версії 0.4.5, яку не публікували окремо: менший розмір програми, перевірка моделі розпізнавання за контрольною сумою, документ лише вбудованою моделлю або Ollama на цьому Mac.
