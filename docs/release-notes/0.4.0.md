# Протокол 0.4.0

## latest.json (вікно оновлення)

Розпізнавання вчиться на цьому Mac: Whisper донавчається на перевірених нарадах уночі або одразу, і нова модель вмикається, лише якщо вона точніша. Кнопки календаря лише відкривають дзвінок, а запис починається і завершується тільки після натискання.

## GitHub release v0.4.0

- Розпізнавання вчиться на цьому Mac. Коли перевірено щонайменше 2 год мовлення, програма пропонує донавчити Whisper на ваших нарадах: уночі або зараз (30–40 хв). Записи і тексти не залишають Mac.
- Нова модель вмикається, лише якщо на останніх перевірених нарадах вона робить помітно менше помилок, ніж поточна (щонайменше на 0,5%). Інакше залишається поточна. Наступне навчання стає можливим після кожних 2 год нового перевіреного мовлення.
- Модуль навчання (близько 75 МБ) завантажується під час першого навчання з релізу learning-engine-1 і перевіряється підписом програми. Без інтернету його можна встановити з файлу: Налаштування → Пам'ять → Модуль навчання.
- Налаштування → Пам'ять: модель розпізнавання, коли донавчати, історія навчань з поверненням попередньої або звичайної моделі, якість розпізнавання за нарадами.
- Налаштування → Конфіденційність: звіт про якість розпізнавання, лише числа. Він не надсилається сам: перед надсиланням видно весь текст, будь-який рядок можна прибрати, звіт відкривається як заявка на GitHub або зберігається у файл.
- Дзвінки: кнопки календаря, «Сьогодні» і нагадування лише відкривають дзвінок. Після відкриття дзвінка Zoom чи Teams з'являється пропозиція почати запис; коли час наради за календарем минув, з'являється пропозиція завершити запис. Запис починається і завершується тільки після натискання.
- Донавчання потребує Mac з Apple Silicon і щонайменше 16 ГБ пам'яті.

ffmpeg-8.1.3.tar.xz — джерельний код FFmpeg (LGPL), з якого зібрано ffmpeg у програмі.

## GitHub release learning-engine-1 (не «latest»)

Модуль навчання для Протоколу 0.4.0 і новіших: Python 3.13, MLX 0.32.4 і код навчання зі scripts/learning-engine. Програма завантажує його сама під час першого донавчання і перевіряє підпис (.sig) ключем оновлень.
