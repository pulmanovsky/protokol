# Протокол 0.4.4

## latest.json (вікно оновлення)

Новий звіт про проблему: Протокол збирає журнал роботи в один файл на робочому столі, ви переглядаєте кожен файл і самі вирішуєте, кому його передати. Під час наради проблемний момент можна позначити одним натисканням.

## GitHub release v0.4.4

- «Довідка → Повідомити про проблему…» тепер складає звіт на цьому Mac: опис проблеми, журнал роботи за 7 днів, технічні дані про вибрану нараду і звіти macOS про падіння програми. Перед збереженням кожен файл можна відкрити. Звіт зберігається одним zip-файлом на робочому столі й нікуди не надсилається сам: його можна передати зручним способом.
- «Позначити проблему» (⇧⌘P, значок у рядку меню, кнопка з прапорцем на панелі запису і у вікні Google Meet) записує в журнал момент, коли щось пішло не так, разом із докладними записами кількох попередніх хвилин.
- Журнал роботи програми ведеться по днях і зберігається 7 днів (до 50 МБ). Однакові записи, що повторюються, згортаються. У журналі немає текстів стенограм і документів, назв нарад, імен учасників і назв аудіопристроїв.
- Біля кожного запису зберігається окремий журнал цієї наради: від початку запису до готового документа.
- Помилки у вікнах програми і аварійні завершення тепер теж потрапляють до журналу. Після аварійного завершення програма пропонує зберегти звіт.
- Звернення на GitHub більше не містять рядків журналу.
