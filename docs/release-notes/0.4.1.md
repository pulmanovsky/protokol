# Протокол 0.4.1

## latest.json (вікно оновлення)

Донавчання враховує лише наради з версії 0.4.0 і лише рядки, які справді перевірено: прочитано, прослухано або виправлено. Кнопку «Позначити все перевіреним» прибрано.

## GitHub release v0.4.1

- Донавчання і перевірка нової моделі беруть лише наради, записані з версії 0.4.0. У старіших нарадах правила «було → стало» змінювали текст самі, також там, де слово було правильним, і модель вивчала ці зміни.
- Враховуються лише рядки, які справді перевірено: прочитано на екрані, прослухано, виправлено або позначено окремо. Програма запам'ятовує, як саме перевірено кожен рядок.
- Кнопку «Позначити все перевіреним» і плашку «Стенограму перевірено не повністю» в документі прибрано. Рядки, позначені цією кнопкою раніше, залишаються перевіреними для стенограми і документа, але не використовуються для навчання.
- «Перевірене мовлення» в Налаштування → Пам'ять рахує лише такі наради і рядки, тож після оновлення число зменшиться. Наступне навчання стане можливим, коли набереться щонайменше 2 год такого мовлення.
