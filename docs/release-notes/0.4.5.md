# Протокол 0.4.5

## latest.json (вікно оновлення)

Програма стала меншою і простішою: прибрано невикористовуваний код і можливість підключати сторонні сервери моделей. Завантажені моделі розпізнавання тепер перевіряються за контрольною сумою.

## GitHub release v0.4.5

- Документ створюється лише вбудованою моделлю або Ollama на цьому Mac. Налаштування стороннього сервера моделей прибрано; якщо його було обрано раніше, програма переходить на вбудовану модель.
- Модель розпізнавання мовлення завантажується з закріпленої версії та перевіряється за контрольною сумою SHA-256. Пошкоджений файл видаляється, і програма пропонує завантажити його ще раз.
- Прибрано невикористовуваний код попередника програми: старий сервер, аналітику, застарілі команди та сценарії для інших систем.
- Шаблон документа може містити слова, після яких наступне слово пишеться з великої літери як назва (наприклад, «вулиця Садова»). Такі слова задаються в пакеті шаблонів.
- Код автоматично перевіряється тестами на GitHub після кожної зміни.
